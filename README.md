# HoneyPass 🍯🛂
**Every AI skill needs a passport.**

HoneyPass is customs & immigration for AI agent plugins (Kiro Powers, Agent Skills, MCP servers).
Scanners *read* a skill. HoneyPass *watches it act* in a honeypot Detention Room, issues signed passports
to clean plugins, and enforces them at runtime with Kiro hooks, including catching rug pulls.

> Built with Kiro for the #KiroUniversity challenge. See `docs/LESSON_MAP.md` for how each Kiro lesson is used.

## Status
🚧 Starter scaffold. Product code is generated through Kiro specs (`docs/SPEC_PROMPTS.md`).

## Quickstart (development)
```bash
# prerequisites: git, uv (https://docs.astral.sh/uv/), Node.js (for the Context7 MCP server), Kiro IDE/CLI
uv sync --all-groups
uv run pre-commit install --hook-type pre-commit --hook-type commit-msg
git config commit.template .gitmessage
bash .kiro/hooks/scripts/quality_gate.sh
```
Open the folder in Kiro and check that steering, hooks, MCP servers and custom agents show up in the Kiro panel.

## Safety note
All "hostile" plugins in `tests/fixtures/plugins/inert-hostile-*` are **inert test fixtures**. They only touch
fake canary values and send to `127.0.0.1`. No real malware is included.
