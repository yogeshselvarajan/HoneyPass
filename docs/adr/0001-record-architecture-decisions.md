# 1. Record architecture decisions
Date: 2026-09-23 · Status: Accepted

## Context
HoneyPass makes security-relevant choices (signing algorithm, sandbox, storage) that judges and users must be able to audit.

## Decision
Use lightweight ADRs in `docs/adr/NNNN-title.md` (Context / Decision / Consequences). Kiro design docs link to ADRs.

## Consequences
Every significant decision in a spec's design.md gets an ADR number.
